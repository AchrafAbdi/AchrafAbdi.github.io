02

Optimized Data Transmission

Previously, the Raspberry Pi transmitted data arrays to the Arduino Mega boards every 0.5 seconds, often sending unchanged information. These repeated transmissions interrupted the Arduino boards' processing and reduced the time available for other tasks.

The communication logic was improved so that the relevant data arrays are sent when a button is pressed on the web interface, instead of being transmitted continuously. This reduces unnecessary communication and allows the Arduino boards to spend more time processing the required functions.

Web button press→Raspberry Pi→Arduino Mega
03

Automatic Recovery with a Watchdog

During operation, the Arduino Mega boards occasionally became unresponsive, particularly when processing tasks were repeatedly interrupted by cyclic communication with the Raspberry Pi. Previously, this could require a manual restart.

A watchdog mechanism was introduced to improve reliability. If an Arduino stops responding for approximately two seconds, the watchdog automatically resets the board. This enables the system to recover without requiring the user to press the reset button manually.

Result: Faster response to control inputs, less unnecessary data traffic, and improved recovery from software lockups.
